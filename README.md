# 🌍 Global Terrorism Machine Learning Project

## 📌 Overview
This project applies 5 Machine Learning Algorithms on the Global Terrorism Dataset.

## 🤖 Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- KNN
- SVM

## 📊 Features
- Data Cleaning
- Visualization
- Model Comparison
- Accuracy Analysis
- Confusion Matrix

## 🛠 Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 📁 Dataset
Global Terrorism Dataset

## 🎯 Objective
Predict whether a terrorist attack was successful based on attack characteristics.
